# Mario Kart 64 Memory Locations

## Memory Map

|Address|Info|
|--- |--- |
|0x1644D0 | Current progress |
|0x0F6BBC | Velocity |
|0x0F69A4 | X Position |
|0x0F69AC | Y Position |
|0x0F69A8 | Z Position |
|0x80164390 | Lap (starts at -1) |
